# Decisions

**Location**: `docs/decisions/`

Architecture decision records, one per component or principle, numbered `NNNN-<slug>.md` in the order they were written. The constitution (`.specify/memory/constitution.md`) holds the binding rule; an ADR holds the context, the decision in full, and its consequences. Consult the ADR for the *why* behind a principle.

Start a new record from `0000-template.md`. An ADR is amended in place with a dated note at the point it changes, never silently rewritten; a decision that is reversed is marked `Superseded by NNNN` rather than deleted.
